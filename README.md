# InvoiceKit — Legal

The Terms & Conditions and Privacy Policy for [InvoiceKit](https://github.com/junaidsaleem/InvoiceKit),
published via GitHub Pages.

This repo intentionally contains only these static pages — no app source code — so it can stay
public (required for GitHub Pages on the free plan) while the InvoiceKit app repo itself stays
private.

Published at: https://junaidsaleem.github.io/invoicekit-legal/

## Updating

Edit `terms.html` / `privacy.html` / `index.html` directly and push to `main` — the
`Deploy Pages` workflow republishes automatically. Bump the `v1.0.0` version references by hand
when the app's version changes; there's no shared build step with the app repo.
